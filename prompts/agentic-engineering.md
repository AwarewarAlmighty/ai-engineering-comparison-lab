# Agentic Engineering Experiment

```text
Inspect the complete registration flow.

Before editing:
1. Identify all relevant files.
2. Explain confirmed problems using code evidence.
3. Create a minimal file-level implementation plan.

Then:
4. Implement the smallest necessary changes.
5. Run targeted tests and the full test suite.
6. Review the final diff for unrelated changes.
7. Report files inspected, files changed, commands executed, test results, and remaining risks.

Acceptance criteria are defined in AGENTS.md.
```
