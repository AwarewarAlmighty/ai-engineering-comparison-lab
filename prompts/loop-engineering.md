# Loop Engineering Experiment

```text
Make the registration test suite pass through a controlled engineering loop.

For every iteration:
1. Select one failing test.
2. Inspect the relevant evidence.
3. State a testable hypothesis.
4. Propose the smallest relevant change.
5. Run the targeted test.
6. Keep, revise, or revert based on the result.
7. Run regression tests before moving to the next category.
8. Record the iteration.

Do not fix all failures in one large edit.
Do not modify unrelated files.
Acceptance criteria are defined in AGENTS.md.
```
